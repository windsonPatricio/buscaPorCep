# Consulta de Localidade via CEP 🧭

Este é um projeto simples em **Java**, desenvolvido como parte do programa **Oracle Next Education (ONE) - Geração Tech - Fundação Alura**, com o objetivo de praticar conceitos de back-end e integração com APIs REST.

## 📌 Objetivo

Permitir que o usuário consulte informações de localidade (como cidade, estado, logradouro) a partir de um **CEP** informado, utilizando uma API pública.

## 🛠️ Tecnologias Utilizadas

- **Java 17**
- **IDE IntelliJ / Eclipse**
- **Biblioteca HttpClient (Java)**
- **JSON (org.json ou Gson)**
- **API ViaCEP** (https://viacep.com.br)

## 🔁 Funcionalidades

- Entrada de um CEP pelo usuário
- Chamada à API ViaCEP
- Tratamento da resposta JSON
- Exibição das informações de localidade no terminal
